# SU音乐 - 纯粹聆听

极简 · 纯净 · 无干扰的音乐播放器 🤓

---

## ⚠️ 重要说明

**本仓库已移除所有在线音乐相关代码，不内置任何音乐播放 API。**

在线播放功能现已不可用，但本地音乐播放功能完好无损。

如需在线播放功能，请开发者自行对接相关音乐 API。

---

## 📌 关于本仓库

本仓库为 SUmusic 的开源代码版本，基于 MIT 许可证开源，仅供学习与交流使用。

**重新开源日期：2026 年 8 月 24 日**

---

## 🎵 特性

- 🚫 零开屏广告 · 零推送打扰
- 📴 离线播放 · 省流省电
- 🎚️ 10 段均衡器 · 多种预设音效
- 📂 智能管理本地音乐文件
- 📜 自动加载 .lrc 歌词文件

## 🔧 开发者指南

本项目已移除内置 API，如需接入在线音乐服务，可参考以下方向：

1. 自行搭建音乐 API 服务
2. 对接第三方音乐 API 接口
3. 修改项目中 `api` 相关模块代码进行适配

具体实现请参阅项目源码中的相关注释说明。
