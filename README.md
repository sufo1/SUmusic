# SUmusic

纯粹 · 离线 · 无广告的 Android 音乐播放器

---

## ⚠️ 重要说明

**本仓库已移除所有在线音乐相关代码，无内置 API。**

在线播放功能已不可用，本地音乐播放功能完全正常。

如需在线播放功能，请开发者自行对接相关音乐 API。

---

## 📌 关于本仓库

本仓库为 SUmusic 开源版本，代码以 MIT 许可证开源，仅供学习交流使用。

**重新开源日期：2026 年 8 月 24 日**

---

## 🎵 特性

- 🚫 零开屏广告 · 零推送干扰
- 📴 离线播放 · 省流省电
- 🎚️ 10 段均衡器 · 多种预设音效
- 📂 智能本地音乐管理
- 📜 支持 .lrc 歌词自动加载

## 🔧 开发者指南

本项目已移除内置 API，开发者如需接入在线音乐服务，可参考以下方向：

1. 自行搭建音乐 API 服务
2. 对接第三方音乐 API 接口
3. 修改项目中 `api` 相关模块代码进行适配

具体实现请查阅项目源码中的相关注释说明。
